# Changelog

All notable public releases of Quiz Simulator are documented here.

## [1.0.0] - 2026-09-22

First public release.

### Added

- Windows desktop application distributed as `QuizSimulator-Windows.zip`;
- single-choice and multiple-choice questions;
- short-answer and free-text questions;
- JSON import with schema v2 and compatibility with v1;
- assisted import of textual PDF question banks;
- Training, Exam and Smart Training modes;
- error history and topic-based learning progress;
- adaptive review selection;
- indexed archive search, filters and favorites;
- question editing and collection update/replace workflows;
- recoverable trash for questions, collections and sessions;
- JSON export;
- validated ZIP backup and restore;
- per-question explanations and personal notes;
- automated tests, smoke tests, linting and benchmarking;
- portable Windows build workflow.
